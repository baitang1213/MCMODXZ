GameBanana 用法：点「① 同步 Mod 列表」拉取全部目录（约 3050 条）→「② 抓取下载链接」批量提取直链 →「③ 导出」。 抓取可随时停止、断点续抓。
Nexus 用法：点「① 同步 Nexus 列表」（94 个 Mod，约 10 秒）→「② 抓取文件信息」获取文件清单； 每个文件可用「文件页」手动下载；如需接口直链，请填写 API Key（且账号为 Premium）。
免责声明：本工具仅通过 GameBanana 官方公开 API 与 Nexus Mods 公开接口读取元数据与链接； 第三方 Mod 的安装与使用请自行评估风险，并遵守《鸣潮》用户协议与各平台规则。
